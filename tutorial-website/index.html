HTML - The Structure

HTML (HyperText Markup Language) is the backbone of any website. It defines the structure and content of web pages using "elements" like headings, paragraphs, and links.

🧱 What HTML Does

  • Creates Structure: Defines headings, paragraphs, lists, and sections
  • Adds Content: Places text, images, videos, and other media
  • Links Pages: Connects web pages together with hyperlinks 
<!DOCTYPE html>
<html>
<head>
    <title>My Page</title>
</head>
<body>
    <h1>Welcome!</h1>
    <p>Hello, world!</p>
</body>
</html>

CSS - The Appearance

CSS (Cascading Style Sheets) controls how HTML elements look. It's responsible for colors, fonts, spacing, layout, and making your website visually appealing.

🎨 What CSS Does

  • Colors & Fonts: Sets text colors, background colors, and typography
  • Layout: Controls spacing, positioning, and page structure
  • Responsive: Makes sites work on mobile, tablet, and desktop
  • Animations: Adds transitions and visual effects

📐 CSS Example

/* Style all headings */
h1 {
    color: purple;
    text-align: center;
}

/* Style a specific class */
.container {
    width: 80%;
    margin: auto;
    padding: 20px;
}

JavaScript - The Brains

JavaScript is a programming language that enables interactive web pages. It allows you to update content, control multimedia, animate images, and much more - essentially making websites dynamic.

⚡ What JavaScript Does

  • Interactivity: Responds to clicks, keyboard input, and mouse movements
  • Dynamic Content: Updates page content without reloading
  • Logic: Performs calculations and decision-making
  • API Calls: Fetches data from servers (weather, news, etc.) 
// Change text when button is clicked
document.querySelector("button").addEventListener("click", function() {
    document.querySelector("h1").innerHTML = "Hello, JavaScript!";
});

// Simple calculation
let price = 20;
let tax = 0.08;
let total = price * (1 + tax);

📦 JavaScript at a Glance

Functions

Reusable blocks of code that perform specific tasks

Detect user actions like clicks, scrolls, and key presses

💡 Remember: JavaScript is like the nervous system - it makes your website think and react!

Types of Websites

Websites come in various forms, each serving different purposes. Here's how they're commonly classified:

Static

Pre-built pages with fixed content. Fast and secure, but requires technical knowledge to update.

Example: Portfolio site

Dynamic

Content changes based on user actions or data. Uses databases and server-side scripting.

Example: Social media platform

E-commerce

Online stores that allow buying and selling products. Include product catalogs and shopping carts.

Example: Amazon, Shopify stores

Blog/CMS

Content Management Systems for publishing articles and managing content without coding.

Example: WordPress, Medium

SPA

Single Page Applications load once and update content dynamically. Fast user experience but SEO can be challenging.

Example: Gmail, Netflix

Landing Page

Focused single-page marketing tools designed to convert visitors into customers with clear calls-to-action.

Example: Product launch pages
